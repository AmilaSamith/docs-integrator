# Migrate to WSO2 Integrator

If you're moving an existing integration platform to WSO2 Integrator, start with the guide for
your current platform. Each guide maps the concepts you already know to their WSO2 Integrator
equivalent, and walks through migrating a representative flow end to end.

- [Migrate from MuleSoft](/migrate/from-mulesoft)
- [Migrate from TIBCO BusinessWorks](/migrate/from-tibco)

Don't see your platform listed? The same underlying concepts — services, connectors, data
transformation, error handling — carry over regardless of where you're migrating from. [Get
started](/get-started/setup/overview) with WSO2 Integrator directly, or reach out on
[Discord](https://discord.com/invite/wso2) for migration guidance specific to your platform.
